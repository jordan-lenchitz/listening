# the supercollider manifesto: toward an ecological machine listening

### axiom 1: the auditory scene is not a dataset
supercollider's decoupling of the language (sclang) from the synthesis engine (scsynth) affords an environment that respects the temporal sanctity of the auditory object as opposed to the fundamental ontology of most mir (sounds as 2-3 dimensional grids of intensities)

### axiom 2: latency is a perceptual reality
in supercollider latency is a *parameter* and so we can model the time-constants of the human ear (integration times, masking windows) with sample-accurate precision by scheduling events on the server's precise clock

### axiom 3: the c-scale is the scale
supercollider allows us to easily define our own spaces where the "distance" between two frequencies is a perceptual relationship

### axiom 4: no black boxes
while the world chases ephemeral "weights" for some sota transformer we explore the possibilities of sound itself and offer only grounded explanations for any and all affordance we predict
